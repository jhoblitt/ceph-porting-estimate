**Linear scale-up of a frozen commit.** The estimate adds features up. It has no term for making separately ported daemons work together, for qualifying a ported OSD or BlueStore for crash consistency, recovery and performance, or for the changes upstream Ceph makes while a port runs. rgw-go is the easy case: it meets the rest of Ceph at one stable library and was tested against a running cluster from its first week. The headline's output is about {{computed.interpretation.scaleUp | times}} times the output of rgw-go's port; the model has no parameter for any of these, so none is sized here.

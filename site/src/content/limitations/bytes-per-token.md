**Bytes per token, and it barely matters.** Tokens are derived from bytes with an assumed value per language. The Go value cancels entirely, and the C++ value's error cancels for C++ code once the expansion is recomputed with it; what is left is each other language's value relative to C++'s. The range is every one of those values scaled by {{computed.variant.bptLow | multiplier}} and {{computed.variant.bptHigh | multiplier}}.

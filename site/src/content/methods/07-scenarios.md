## Scenarios

A scenario is the baseline parameters with some replaced or scaled, and the two switches set. Each has a role. The central one is the estimate. The low and the high ones show how far assumptions of the size this report already considers move it; neither is a limit. A reference one is shown for scale and is not an outcome. The estimate page draws the low, central and high scenarios on one scale from zero dollars, with the band between low and high and the selected one marked, and each reference scenario as a labelled tick on the same scale.

::: scenarios

A scenario with the reference role prices one read of every headline file and one write of its translation, with no new tests (Ceph's own are still ported), no review and no re-reading: what a "translate every line once" estimate assumes. Nothing about porting Ceph that way has been measured.
